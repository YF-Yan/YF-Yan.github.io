全球与中国宠物行业发展趋势量化分析及出口政策影响模拟

🏅 项目荣誉：2024 年亚太地区大学生数学建模竞赛 (APMCM) 国家三等奖

该项目是一项针对宠物产业经济的专项研究。通过对全球及中国 2019-2023 年行业数据的挖掘，深度分析了市场演变逻辑，并针对国际政策变动（如关税调整）构建了前瞻性模拟模型。

  • 多维趋势建模： 整合多方贸易统计数据，运用 时间序列分析与多元回归 技术，揭示了中国宠物食品进出口规模的增长曲线与核心驱动因素。
  • 政策冲击仿真： 创新性地引入 Logistic 增长模型，量化模拟了不同关税梯度对出口贸易额的影响，为行业应对国际贸易不确定性提供数据支持。
  • 工程实现与验证： 基于 Python 构建全流程数据处理管道，利用 Scikit-learn 进行模型拟合，通过 R² 与 MSE 指标进行精密度校准，并实现了高度可视化的研究报告。
Industrial Analysis Quantitative Modeling Logistic Growth Python

Mini-Kernel：用户态微内核仿真系统

基于 C/S 架构，在用户态模拟操作系统核心机制，重点探索存储优化与并发控制。

  • 架构解耦： 设计了基于共享内存的异步消息队列，成功解耦 GUI 与内核进程。
  • 存储引擎优化： 为自研 FAT 文件系统设计了采用 Write-Back 策略的 LRU 缓冲池，将 I/O 次数降低了约 40%。
  • 并发控制： 引入读者-写者锁（RW-Lock）机制，解决多用户并发访问冲突，提升系统吞吐量。
C/C++ Operating System LRU Buffer Pool Concurrency
